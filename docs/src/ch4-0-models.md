# Models

A Model in Cloesce defines a structure hydrated from sources of persistent data, such as:

- [D1 databases](./ch3-2-d1.md)
- [Durable Objects](./ch3-3-durable-objects.md)
- [KV namespaces](./ch4-3-kv-fields.md)
- [R2 buckets](./ch4-4-r2-fields.md).

Once defined, a Model is a first class citizen across the frontend, backend, and database layers of your application, capable of housing [API endpoints](./ch6-0-apis.md) and being serialized to the client.
